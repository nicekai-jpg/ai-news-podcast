# ✨ 科技新闻日报 | 2026年07月29日

**导语**：今日 AI 领域迎来架构级与生态级的双重震荡——全球首个 Agentic 扩散模型横空出世，打破了自回归在长程智能体任务上的统治；而 Google 与字节则不约而同地将"Agent"作为新一代产品叙事的核心抓手。与此同时，中国开源模型继续在全球榜单上攻城略地，AI 顶尖人才的流动也折射出行业格局的深层洗牌。

## 🚀 重磅解读

### 一、Agentic 扩散模型问世：架构范式的"第二次迁移"

**事件背景**：长期以来，大语言模型主导的 Agent 框架几乎全部建立在自回归（Autoregressive）架构之上——逐 token 生成、链式思考（CoT）、逐步规划。扩散模型虽在图像与视频生成领域如日中天，但在需要长程规划与多步决策的 Agent 任务上却被视为"不擅长推理"的异类。

**核心突破点**：今日亮相的全球首个 Agentic 扩散模型，首次将扩散过程与 Agent 任务深度耦合。其关键创新在于"边行动边纠错"机制——模型能够在生成轨迹的同时，对已完成的步骤进行反向去噪式修正，并将上下文窗口扩展至 128K，性能追平主流自回归 Agent。这不仅意味着架构层面的范式转移，更暗示了一条全新的训练-推理协同优化路径。

**对行业生态的深远影响**：
- **对训练侧**：扩散模型的并行生成特性天然适配高吞吐训练，推理成本有望进一步下探，这对依赖高 QPS 的 Agent 产品（如客服、代码助手）尤为关键。
- **对应用侧**：128K 长上下文的稳定支持，让 Agent 终于能够承载真正意义上的"长任务"——比如跨工具、跨文件、跨会话的复杂工程。
- **对竞争格局**：若该架构被开源并被中国头部实验室跟进，可能彻底改写"自回归 = Agent"这一被默认多年的等式。Meta、Anthropic 等公司或将被迫加速其在非自回归方向上的研究投入。

### 二、Gemini 3.6 Flash + Managed Agents：Google 的"Agent 工业化"反击

**事件背景**：在过去一年中，OpenAI 与 Anthropic 在 Agent 能力上持续领先，Google 虽拥有 Gemini 这一顶级基座，却始终缺少一套成熟、可商用的 Agent 托管基础设施。今日 Google AI Blog 发布的更新，被外界普遍视为其"补齐最后一块拼图"的关键动作。

**核心突破点**：本次更新包含三大支柱：**3.6 Flash 模型**（极致性价比的轻量级旗舰，专为高频 Agent 调用优化）、**Managed Agents 托管服务**（开箱即用的会话状态管理、工具调用编排、长时记忆），以及 **Hooks & Triggers**（允许开发者在 Agent 生命周期的任意节点注入自定义逻辑）。三者共同构成了 Google 首个真正意义上的"Agent 即服务"（AaaS）完整栈。

**对行业生态的深刻影响**：
- **生态绑定**：通过将 Agent 能力深度集成进 Vertex AI 与 Workspace 体系，Google 正试图将其在企业市场的既有优势直接转化为 Agent 时代的护城河。
- **开发者心智**：Hooks 机制的引入对标 LangChain、CrewAI 等中间件框架，可能引发新一轮"是否还需要独立 Agent 框架"的大讨论。
- **价格战信号**：3.6 Flash 的命名本身就暗示着 Google 在用 Flash 系列的"快与便宜"碾压对手，将 Agent 推理单价打到新的低点。

## ⚡ 前沿情报

- **豆包搜索正式"走出豆包"**：字节跳动宣布将豆包的搜索能力以 API 形式开放给第三方 Agent 调用。这意味着豆包不再只是一个对话产品，而是转身成为 Agent 时代的基础设施供应商——搜索作为 Agent 获取实时信息的"感官"，其开放程度将直接决定下游 Agent 的能力上限。此举对标 Perplexity 的 Sonar 与 OpenAI 的 Web Search，标志着中文大模型生态首次出现真正意义上的"搜索能力层"。

- **Kimi K3 与 Unlimited OCR 包揽全球榜单前二**：月之暗面旗下 Kimi K3 模型在权威榜单上登顶，Unlimited OCR（无限制长度文档识别）紧随其后位列第二。这是中国开源模型连续多周在国际舞台上的又一次强势刷屏。从长上下文到 OCR，再到推理能力，中国团队正在"逐项击破"过去被认为难以攻克的硬核指标，开源生态的话语权正持续向东方转移。

- **翁荔从 Thinking Machines 离职，加盟不足 20 个月即告别**：作为 AI 领域最受关注的高管之一，翁荔此前从 OpenAI 转投 Mira Murati 创办的 Thinking Machines，被视为初创公司"挖角巨头"的标志性事件。然而仅 20 个月便传出离职消息，叠加近期硅谷多家明星 AI 初创出现核心人员动荡，折射出**大模型创业公司正进入"洗牌期"**——当产品矩阵逐渐收敛、融资节奏放缓，曾经的明星团队能否经受住规模化与商业化的双重考验，已成为普遍性命题。
