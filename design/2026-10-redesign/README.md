# 2026-10 站点重排设计沙盒

这个目录只用于 Open Design 设计，不参与构建、不参与 CI。

## 在 Open Design 桌面版里怎么打开

1. 打开 Open Design。左侧是**图标导航栏**，没有文字叫「新建项目」的项；先点左侧的文件图标（悬停显示「全部项目」/「草稿」）进入项目页。
2. 在项目页右上角（有项目时）或页面中央（列表为空时）点「+ 新建项目」，打开新建项目对话框。
3. 在对话框里**往下滚到底部**，找到「打开文件夹」按钮（在「创建」按钮下方，容易被折叠在滚动区里）。
4. 点「打开文件夹」，选择本目录：`design/2026-10-redesign`。
5. 选完目录会**直接导入并打开项目**，不需要再点「创建」，也不需要先填项目名称/设计体系。
6. 项目打开后，把 `brief.md` 的内容贴进对话框，并把 `content/` 里的文件作为附件加上。

说明：新建对话框里的「其它」标签不是必需步骤；「打开文件夹」在任意标签页底部都能用。若想让导入的项目不绑定原型技能，可以先切到「其它」再点「打开文件夹」。

如果对话框底部确实没有「打开文件夹」，说明当前版本的宿主桥没暴露这个入口；不要用系统自带的 `/usr/bin/od`（那是八进制 dump 工具）。把截图发我，我用 Open Design 自带 daemon 的接口帮你导入。

## 给 Open Design 的第一条消息

```text
请先阅读 brief.md 和 content/ 里的真实内容样本，然后给我 3 个信息架构方向
（每日刊 / 编辑台 / 杂志头版），每个方向都要有桌面 1440 和移动 390 两个版本。
不要直接改 index.html，把三个方向分别放到 directions/A、directions/B、directions/C。
```

## 边界

- 不要修改 `src/`、`site/`、`data/`、`config/`；这个目录之外都不是设计沙盒。
- 根目录的 `index.html` 是当前线上页面的快照，只作参考，不要把它当最终产物。
- 快照里的音频分片不在仓库里，播放器不会真的出声；这是预期行为，不影响看排版。
- 设计稿可以是独立 HTML，但最终移植回 `src/ai_news_podcast/presentation/site_builder/` 时必须是纯 HTML/CSS/vanilla JS。
