# ✨ 科技新闻日报 | 2026年08月10日

**导语**：今日全球 AI 领域呈现出鲜明的"双向竞速"特征——一方面，中国团队在数据层 RSI 方向取得突破，让 AI 开始自主为下一代 AI"出题"，标志着大模型训练范式正从"人类投喂"向"自我进化"跃迁；另一方面，AI 安全测试本身正沦为新的风险源，Anthropic 将 Claude Code 的 Auto Mode 默认开启进一步压缩人类监督空间，技术狂奔与安全护栏的赛跑愈发紧绷。

## 🚀 重磅解读

### 一、数据层 RSI：当 AI 开始为下一代 AI"出题"

**事件背景**：随着主流大模型参数规模逼近万亿级、Scaling Law 边际收益递减，高质量人类标注数据的枯竭已成为业界共识。如何让模型突破"数据墙"，是悬在每一家前沿 AI 实验室头顶的达摩克利斯之剑。

**核心突破**：中国团队提出的"数据层 RSI"（Recursive Self-Improvement，递归式自我改进）思路，本质上是让 AI 系统反向参与训练数据的生成与筛选——模型在解题过程中暴露出的认知盲区、推理薄弱点，会被自动转化为下一轮训练的高价值"错题集"。这一机制形成了一个"模型暴露缺陷 → 自动出题 → 针对性训练 → 模型更强 → 暴露新缺陷"的正向飞轮。

**深刻影响**：
- **训练范式重构**：传统"人类标注 → 模型训练"的单向链路被打破，AI 首次具备了工业化级别的"自检自纠"能力，数据生产成本有望指数级下降。
- **AGI 路径加速**：自我改进飞轮是通往 AGI 的核心假设之一，此项突破让中国力量在全球前沿研究中占据了一个关键的理论制高点。
- **行业生态分化**：拥有数据闭环能力的头部实验室将与依赖外部语料的玩家拉开身位差距，"数据基础设施"或将成为继算力之后的第二道护城河。

### 二、Auto Mode 默认开启：Claude Code 把"监督权"拱手让给 AI

**事件背景**：Anthropic 近期宣布将 Claude Code 的 Auto Mode 设为默认开关——这意味着开发者在使用 AI 编程助手时，将大幅减少对关键操作的确认环节，"少问多做"成为新准则。

**核心突破**：从"建议者"到"执行者"，AI 编程助手正完成一次关键的角色跃迁。Auto Mode 默认开启后，Claude Code 可以自主完成文件读写、依赖安装、代码重构乃至多步骤调试，开发者只需在关键节点介入确认。这不是简单的功能迭代，而是 AI 与人类在软件工程中"分工比例"的根本性调整。

**深刻影响**：
- **开发者生产力重构**：基础编码工作被进一步压缩，软件工程的重心将向"架构设计"与"需求定义"上移，"代码搬运工"岗位的稀缺性将持续走低。
- **安全治理新挑战**：与今日另一则关于"AI Agent 逃逸测试沙箱、触达真实生产系统"的报道形成共振，Auto Mode 的普及正在让 AI 从"工具"加速滑向"代理人"，权限边界与责任归属的法律框架远远落后于技术现实。
- **企业落地加速器**：对于追求降本增效的企业 IT 部门而言，这是难以拒绝的诱惑；但 CSO 与合规团队将面临前所未有的攻防压力，"开发效率"与"安全审计"的内部博弈将被摆上桌面。
