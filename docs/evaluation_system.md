# 评测体系

## 一、先分清四层，不要拿一个分数评全部

```
L0 标签质量   字段判得对不对
L1 阶段效果   召回/粗排/精排/重排各留下多少
L2 产物质量   日报、播客、音频好不好
L3 运维       成功率、耗时、成本
```

## 二、金标准怎么建

```
全量事件（7 天）
   ↓ 分层抽样：领域 × AI 相关度 × 来源等级 × 语言
500 条（300 调参 + 200 锁定测试）
   ↓ 双人标注 20%，分歧仲裁
冻结版本 + 哈希，测试集不再改动
```

标注文件每行：

```json
{"event_id": "...", "title": "...", "fields": {"ai_relevance": "core"}, "annotator": "human_a", "reviewed": true}
```

规则：

- 抽样必须包含“顺带提 AI”“汽车/金融/消费”难例，不能只抽 AI 新闻；
- 测试集只评不调；调参看训练集；
- 每字段先算标注者一致性，κ < 0.6 的字段先改定义，不急着上模型。

## 三、指标

### L0 标签

| 类型 | 指标 | 说明 |
|---|---|---|
| 单标签 | accuracy | 附 Wilson 95% 置信区间 |
| 单标签 | macro F1 | 类别不均衡时看这个 |
| 多标签 | micro F1 | 整体命中 |
| 多标签 | 平均 Jaccard | 集合重合度 |
| 有序刻度 | MAE | 误差大小 |
| 有序刻度 | 二次加权 kappa | 人工一致性 |
| 证据 | 证据精确率 | 抽查证据是否真的支持标签 |
| 不确定性 | 覆盖率-风险曲线 | 高置信度部分准不准 |

报告必须带：`n`、分子/分母、置信区间、未匹配数量。

### L1 推荐

| 指标 | 定义 |
|---|---|
| recall@k | 金标准正样本中被召回的比例 |
| precision@k | top k 中正样本比例 |
| nDCG@k | 按相关度分级的排序质量 |
| 漏斗保留率 | 每阶段保留数 / 上一阶段数 |
| 非 AI 误入率 | top8 中非 AI 事件比例 |
| 重大 AI 漏放率 | 金标准“必发”事件没进 top8 的比例 |
| 多样性 | 主体/主题/来源去重数 |

### L2 产物

| 对象 | 指标 |
|---|---|
| 日报 | 事实支持率、关键事实覆盖率、观点/事实分离 |
| 日报点评 | 问题命中率、修正建议可执行率 |
| 播客文稿 | 事实支持率、章节完整度、口播可读性 |
| 播客点评 | show notes 覆盖度、章节导语质量 |
| 音频 | 抽样 WER、时长、响度 |

人工评分用 1–5 分锚点，不用“1.0”这种无信息分数。

### L3 运维

成功率、p50/p95 耗时、单日 token 成本、源失败率、artifact 完整率。

## 四、报告规则

- 没有金标准的指标只能标“诊断”，不能叫准确率；
- 样本 < 30 不给结论，只给原始计数；
- 换数据必须重算，不跨批次比较；
- 每次报告带数据版本、配置哈希、样本量；
- 未匹配样本单列，不能悄悄丢弃。

## 五、决策门槛

| 决策 | 门槛 |
|---|---|
| 开 AI 准入门槛 | 非 AI 误入率 ≤ 2%（95% 上限） |
| 开 LLM 标注 | 相对规则 micro F1 提升，且置信区间不跨 0 |
| 换精排权重 | nDCG@8 提升，配对 bootstrap CI 不跨 0 |
| 上线新模板 | 人工评分不低于旧版，且事实支持率不降 |

## 六、已落地

- `business/eval/stats.py`：Wilson 区间、bootstrap CI、Cohen's kappa、ECE；
- `business/eval/tagging_eval.py` + `scripts/eval_tags.py`：按字段算 accuracy/F1/CI，
  未匹配单列；
- `label_coverage`：空白率只作诊断，新增证据覆盖率；
- `review_quality`：改名结构完整度，不冒充内容质量。
