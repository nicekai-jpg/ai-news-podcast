图 1 · 每日流水线时序图（UML Sequence）

sequenceDiagram
    autonumber
    participant CRON as GitHub Actions 定时
cron 21:43 UTC
    participant RUN as runner.run_pipeline
    participant NEWS as 新闻轨
fetch→去重→打分
    participant R as 项目轨
gh_radar.build_radar
    participant GH as GitHub API
    participant WR as podcastwriter
editor→writer 两段 LLM
    participant REP as 日报 report
    participant PUB as TTS→publish→gh-pages

    CRON->>RUN: podcast-pipeline --date D
    RUN->>NEWS: 抓取约 45 个 RSS/Atom 源
    NEWS->>NEWS: 去重 / 聚类 / 五维打分
    NEWS-->>RUN: raw_items + stories

    rect rgb(232, 244, 255)
        note over R,GH: 项目轨：任何异常只记 StageFailed，正片照常
        RUN->>R: build_radar(配置, D, 新闻标题)
        R->>GH: search created 大于 D-30天 且 stars>=500
        GH-->>R: 前 30 个候选仓库
        R->>R: 硬过滤：合集/无描述/无许可证/停更出局
        R->>R: 30 天排重：已推荐过的出局
        R->>R: 写快照 snap_D.json（明日算增速的基线）
        R->>GH: 前 12 名逐个拉 README
        GH-->>R: 截取安装/Quickstart 小节原文
        R->>R: 评分 0.5增速 + 0.3可上手 + 0.2交叉热度 + 0.1AI主题
        R-->>RUN: 主推×1 + 备选×2，挂到 brief["radar"]
    end

    RUN->>WR: brief（可能含 radar）
    WR->>WR: editor：新闻大纲 + 「## 项目雷达」（只讲主推）
    WR->>WR: writer：对谈稿，栏目 300-500 字
    RUN->>REP: 日报（雷达章节由代码生成，零幻觉）
    RUN->>PUB: MP3 合成 → 站点/feed 发布
