# 无人工标注的闭环评测与推荐体系

## 0. 先讲清楚能做什么、不能做什么

没有人工金标准，**不能证明“准确率”**，只能证明：

- 多信号是否一致；
- 标签/排序是否稳定；
- 证据是否支持结论；
- 护栏是否守住；
- 多目标下结果是否更好。

所以这里的“金标准”换成 **共识标签（silver labels）**：
规则 + 多个 LLM 评委 + 来源元数据，多数一致才算可信；不一致标 `uncertain`。

```
准确率  → 不可得（没有真值）
一致性  → 可测
稳定性  → 可测
证据支持 → 可测
护栏     → 可测
多目标收益 → 可测（相对基线）
```

## 1. 数据采集层

每天固定产出并归档：

| 数据 | 内容 |
|---|---|
| raw items | 标题、摘要、全文、来源、时间、分类 |
| events | 聚类结果、代表标题、item 列表、来源数、独立来源数 |
| labels | 规则标签 + LLM 标签 + 共识标签 + 证据 + 置信度 |
| shortlist | top8 与全部候选、每阶段淘汰原因 |
| products | 日报、文稿、点评、音频元数据 |
| ops | 各 Stage 耗时、token、失败源、artifact 大小 |

采集质量指标：

- 源覆盖率 = 当日有产出的源 / 启用源；
- 全文率 = 全文成功 items / 总 items；
- 新鲜度 = 24h 内 items / 总 items；
- 去重率 = 重复 items / 原始 items；
- 失败源清单。

## 2. 自动标注层（silver labels）

```
标题/导语规则
     +
实体/行业/技术词典
     +
LLM 评委 A（严格）
LLM 评委 B（宽松）
LLM 评委 C（结构化）
     ↓
多数一致 → silver
不一致 → uncertain
```

规则：

- LLM 只选枚举，必须给证据；证据不在原文直接作废；
- 三个评委用不同 prompt/温度/模型，降低同源偏差；
- 共识度 = 一致评委数 / 有效评委数；
- 置信度 = 共识度 × 证据强度；
- 每天抽样 5% 做“同一输入重复跑”，看标签是否漂移。

## 3. 指标定义

### 3.1 标注质量（无真值）

| 指标 | 定义 | 用途 |
|---|---|---|
| 评委一致率 | 两两一致对数 / 总对数 | 标注可信度 |
| Fleiss κ | 多评委一致性 | 字段是否定义清楚 |
| 证据支持率 | 有原文证据的标签 / 总标签 | 防幻觉 |
| 跨源一致率 | 同事件不同 item 标签一致的比例 | 防单条带偏 |
| 重复稳定率 | 同输入重复跑标签相同的比例 | 防随机漂移 |
| 不确定率 | uncertain / 总数 | 需要人看或降级 |

### 3.2 推荐质量（代理指标）

| 指标 | 定义 |
|---|---|
| silver precision@8 | top8 中 silver 正样本比例 |
| silver nDCG@8 | 按 silver 相关度分级的排序质量 |
| 覆盖率 | top8 覆盖的不同主体/主题数 |
| 来源结构 | top8 中 tier1/tier2/tier3 比例 |
| 新鲜度 | top8 中 24h 内事件比例 |
| 重复率 | top8 中同事件/近似标题比例 |
| 护栏通过率 | 非 AI 漏入 = 0、重大 AI 漏放 ≤ 阈值 |

### 3.3 产物质量（无人工）

| 对象 | 指标 |
|---|---|
| 日报 | 每个事实句能否在 evidence 中找到支持；关键事件覆盖率 |
| 文稿 | 事实句支持率；章节完整度；长度/轮次 |
| 点评 | 问题是否带 evidence_id；修正建议是否可执行 |
| 音频 | 时长、静音比例、语速异常 |

### 3.4 稳定性与鲁棒性

- 同一事件在不同日期/来源下标签是否一致；
- 去掉一个来源后排序是否大幅变化（rank correlation）；
- 标题轻微改写后标签是否不变；
- 不同 LLM 评委排序一致性（Spearman）。

## 4. 综合评分

```
Quality =
  0.30 × silver_nDCG@8
+ 0.20 × 证据支持率
+ 0.15 × 评委一致率
+ 0.10 × 覆盖率
+ 0.10 × 新鲜度
+ 0.10 × 来源结构
+ 0.05 × 重复率惩罚
- 护栏违规罚分
```

所有分项先归一化到 0–1；护栏违规直接判不通过，不参与加权。

## 5. 闭环优化

```
每日 artifact
   ↓
自动评测（silver + 证据 + 稳定性 + 护栏）
   ↓
滚动 7 天窗口：均值 - 0.5×标准差
   ↓
参数搜索（权重/阈值/配额）
   ↓
影子运行 3 天
   ↓
优于基线且护栏通过 → 灰度 → 全量
   ↓
指标漂移/护栏失败 → 自动回滚
```

规则：

- 调参只用过去 7 天，留出未来 3 天验证；
- 每次只改一组参数，避免不可归因；
- 所有配置带版本号，结果可复现；
- 单日提升不算数，必须跨日稳定。

## 6. 监控与告警

- 源健康：失败率、空源数；
- 标注：不确定率、证据率、重复稳定率；
- 推荐：silver nDCG、护栏、多样性；
- 产物：事实支持率、结构完整度；
- 运维：成功率、p95 耗时、token 成本。

阈值：

| 指标 | 告警线 |
|---|---|
| 评委一致率 | < 0.7 |
| 证据支持率 | < 0.9 |
| 不确定率 | > 15% |
| 非 AI 漏入 | > 0 |
| p95 耗时 | > 2h |

## 7. 这套体系的边界

- silver 标签是“评委共识”，不是真理；评委有偏，体系就有偏；
- 只能优化“与评委一致 + 证据充分 + 稳定 + 多样”，不能保证“用户喜欢”；
- 若以后有页面点击/播放完成率，应作为外部信号接入，替换部分代理指标；
- 自动闭环适合做**回归与护栏**，不适合做“绝对质量”断言。
